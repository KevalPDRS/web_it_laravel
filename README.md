# Laravel E-commerce Demo

My demo Laravel e-commerce project by [@fundaofwebit](https://www.youtube.com/@fundaofwebit) on YouTube.

## Features
- Product listing
- Cart functionality
- Basic e-commerce flow

## Tech Stack
- Laravel 10
- Blade templates
- MySQL

## Then run

- git add README.md
- git commit -m "Add README file"
- git push

## Clone Laravel Repo

    ## 1. Run the git clone command
    - git clone https://github.com/KevalPDRS/web_it_laravel.git
    ## 2. Go into the project folder
    - cd web_it_laravel
    ## 3. Install dependencies using Composer
    - composer install
    - (If you don’t have Composer installed, do that first.)
    ## 4. Copy the .env file
    - copy .env.example .env
    - Or manually create .env based on .env.example.
    ## 5. Generate Laravel app key
    - php artisan key:generate
    ## 6. Set up your .env for database, mail, etc
    ## 7. Run migrations
    - php artisan migrate
    ## 8. Serve the app locally
    - php artisan serve
    ## 9. Visit http://127.0.0.1:8000 in your browser
